# VF-CL Adaptive20 仅原始样本回放开发留出实验

## 实验边界

本实验把每类 20 个**原始样本**作为唯一持久回放记忆。`sample_replay_only=1` 关闭持久原型缓存、原型损失、SDC 和特征蒸馏，仍保留 logit/party 蒸馏、FIM、BiC 和由样本支持的最终自适应双分支头。因此，它不是纯 ER。全部新读数来自训练数据划出的固定开发留出集；正式测试加载器与评估均未运行，表中数值不是正式 `AA_final`。

训练源码固定于 `99e1da7e05e7eeb8b57587b6d3a75c6eaa490066`。每组独立训练，种子为 54 或 55。源码、配置、数据与留出清单的哈希、退出码、冻结状态、留出读数和正式数据访问记录均在机器台账及归档中核对。每个完整运行目录流式备份到本机 D 盘，并按远端逐文件 SHA-256 清单复验；本机 C 盘另存留出读数。

## 读数观察

两种子平均 Class-IL / Task-IL 在 ISOLET 为 `90.82% / 99.28%`，UPMC 为 `79.33% / 92.22%`，CIFAR-100 为 `35.28% / 74.10%`。CIFAR-100 的 Task-IL 与 Class-IL 相差 `38.82` 个百分点，说明在这个开发留出协议下，跨任务统一判别比给定任务后的判别更困难。这只是本模式的描述性读数；两种子与不同机器的运行不足以支持相对其他机制的因果或速度结论。
