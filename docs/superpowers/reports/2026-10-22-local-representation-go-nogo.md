# 各方本地旧样本表示约束：立项判断（2026-10-22）

**判定：当前候选 C 暂不作为新方法立项，也不启动训练。** 技术上可以让各方用保存的旧样本切片和上一任务底层模型，计算本地表示漂移损失；但目前能写出的区别主要是把已知的旧样本特征蒸馏移到现有逐方模型上。它尚未构成足够清楚的纵向联邦特有新机制。**这是新颖性关口未通过，不是实验验证 C 无效：C 从未训练，论文中不得写成“本地约束没用”。** 本文献核查是针对性初筛，未检出完全相同工作不等于证明首创。

## 与冻结代码核对

冻结生产提交 `e2a559dc4945729848225cf21fdc95451762c231` 的 `cl_methods/proto_evolve.py` 已在当前任务批次上计算逐方旧、新 **logit 贡献**的 PartyKD（约 539、605–624 行）；这不等同于直接匹配各方底层表示，但“逐方约束”本身已有。该文件还有聚合后表示的平方距离约束开关（约 639–644 行），而 `config.py` 的仅样本模式强制 `feat_distill_weight=0`。FIM 冻结各方本地参数亦已存在。因此候选 C 的当前变化主要是**输入换成保存的旧样本，损失落在各方底层表示**，而非首次提出本地抗遗忘。

现有 `head_raw_replay` 由单进程从拼接的完整原始输入选取并集中存放（同文件约 348–371、1100–1106 行）。在它上面模拟按方切片，只能验证算法和估算**额外回放通信**；不能声称各方物理隔离持有数据、隐私已保证，或整个 VFL 训练零通信。旧底层教师和新增本地计算也须单列成本。

## 可证伪问题与停点

如果将来另立研究，公平的基本对照应是：A＝冻结仅样本方法；C＝旧样本的各方本地表示约束；D＝**同一旧样本、教师、损失形式与权重**下的聚合后表示约束。要检验的是 C 相对 D 的精度与**新增回放通信**权衡，而不是 C 是否补上某个已见 ISOLET 测试分数。新方案须先明确超出“POD-flat 分别用于各方”的具体机制、真实部署边界和计量规则，再用未参与旧探索的种子锁定协议，依次做身份核对、预检、配对开发实验和预设门槛判断。

**当前停点在第一关：新机制尚未写清。** 不移植候选 C、不沿用 54/55/58/59/60/61/62 选择其超参，也不把已关闭的回放 A/B 接成续作。更稳妥的近期工作是用冻结的仅样本版结果与已完成审计撰写论文，并如实披露其验证访问、额外计算和单进程模拟边界。

**探索线状态：**推理期 party 路由已因开发读数未支持而关闭；普通训练期回放已因预设稳定性门槛未过而关闭；候选 C 因新增机制不清而未立项。三个结论性质不同，均不改变正式种子 42/43/44 的冻结结果。
