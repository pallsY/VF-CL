# F-off 正式后续运行：启动前 v3 更正

本文件追加于 v1 协议及 v2 更正。v2 已封存代码、清单和独立锚点，但**没有启动任何训练或访问正式测试**；这些记录原样保留。

第二次代码复审发现：v2 双卡队列在一方失败时只停止后续启动，另一方已运行的子进程仍可能继续到正式测试。v3 将每个作业放在独立进程组；一方失败或队列异常时，立即向其他在途作业的进程组发送终止信号，逾时强制终止，保留已产生的日志和失败记录。Linux 预检必须实际验证兄弟进程终止。

新结果根为 `/brf/users/yangxx/VFCL-results/f-off-formal-followup-v3-20261102`。v1、v2 的方法、输入、种子、预算、读数、披露要求不变。v3 必须在首次正式作业前重新封存代码、九项清单与独立锚点；旧根不得删除或重用。
