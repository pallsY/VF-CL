# F-off 正式后续运行：启动前 v4 更正

本文件追加于 v1、v2、v3。v3 已封存代码、清单和独立锚点，但**没有启动训练或访问正式测试**；旧记录继续保留。

最终代码复审指出父调度进程收到 SIGTERM/SIGINT 时，v3 的独立 GPU 子进程组可能脱离调度而继续运行。v4 在调度进程内安装这两种信号的 fail-stop 处理，终止已登记的作业进程组；对调度循环异常也先终止在途作业，再写失败记录。Linux 预检必须实测父进程信号处理与兄弟进程组终止。

新结果根为 `/brf/users/yangxx/VFCL-results/f-off-formal-followup-v4-20261102`。方法、输入、种子、预算、读数和披露要求不变。须在首次 v4 正式作业前重新封存 v4 代码、九项清单和独立锚点；v1–v3 根均不重用。
